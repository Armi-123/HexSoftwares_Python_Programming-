## 📂 Project Structure

### 📁 Task 1 – Python Fundamentals

#### 1️⃣ Fibonacci Generator

Generate Fibonacci number sequences using Python loops and functions.

#### 2️⃣ Voice Assistant

A voice-controlled assistant capable of:

* Telling current time and date
* Opening Google and YouTube
* Playing songs on YouTube
* Responding to voice commands

#### 3️⃣ Tic-Tac-Toe Game

A console-based Tic-Tac-Toe game where users play against the computer using Python's random module.

---

### 📁 Task 2 – Intermediate Python Applications

#### 1️⃣ Web Scraper

Extracts data from websites using:

* BeautifulSoup
* Requests
* Pandas

Scraped information is stored in CSV format for further analysis.

#### 2️⃣ Expense Tracker

A simple expense management application that allows users to:

* Add expenses
* Categorize spending
* Generate expense summaries
* Store data in CSV files

#### 3️⃣ Rent Calculator

Calculates:

* House Rent
* Electricity Bills
* Food Expenses
* Total Monthly Expenses
* Individual Cost Per Person

---

### 📁 Task 3 – Advanced Python Projects

#### 1️⃣ Geolocation Tracker

Tracks geographical locations using IP addresses and:

* Retrieves city, state, and country details
* Displays latitude and longitude
* Generates an interactive map

#### 2️⃣ Memory Puzzle Game

A console-based memory matching game featuring:

* Card matching mechanics
* Interactive gameplay
* Logical thinking challenges

#### 3️⃣ Personal Expense Tracker

An enhanced expense management system with:

* Expense recording
* Category-wise summaries
* Monthly expense reports
* CSV-based storage
