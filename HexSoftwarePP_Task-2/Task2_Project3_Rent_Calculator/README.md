# 🏠 Rent Calculator using Python

## 📌 Project Overview

The Rent Calculator is a simple Python-based application designed to calculate the rent contribution of each individual sharing a rented accommodation. The program takes the total rent, electricity bill, food expenses, and number of persons as input and calculates the amount each person needs to pay.

This project demonstrates the use of Python variables, user input handling, arithmetic operations, and basic financial calculations.

This project was developed as part of the **Hex Softwares Python Programming Internship**.

## 📈 Project Workflow

### 1. Input Collection

The user enters:

* House Rent
* Electricity Bill
* Food Expenses
* Number of Persons

### 2. Expense Calculation

The program calculates:

Total Expense = Rent + Electricity Bill + Food Expenses

### 3. Per Person Calculation

Rent Per Person = Total Expense ÷ Number of Persons

### 4. Display Results

The application displays:

* Total Expense
* Number of Persons
* Rent Per Person
