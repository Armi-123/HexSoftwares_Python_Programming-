# Voice Assistant Project using Python

## 📌 Project Overview

The Voice Assistant Project is a Python-based application designed to perform voice-controlled tasks through Speech Recognition and Text-to-Speech technology. The assistant listens to user commands, processes them, and responds accordingly by providing information, opening websites, and automating simple tasks.

This project demonstrates practical Python programming skills, automation concepts, speech recognition techniques, and basic AI-powered interactions.

---

## 🎯 Objectives

* Develop a voice-controlled assistant using Python.
* Implement Speech Recognition functionality.
* Convert text responses into speech output.
* Automate common tasks through voice commands.
* Open websites and perform web-based actions.
* Play songs directly from YouTube.
* Provide date and time information through voice interaction.

---

## 📊 Project Features

### Voice Recognition

* Capture voice commands through a microphone.
* Convert speech into text using Google Speech Recognition.

### Text-to-Speech

* Convert text responses into spoken audio.
* Provide interactive voice feedback to users.

### Information Services

* Current Time Information
* Current Date Information
* Person Search Functionality

### Browser Automation

* Open Google using voice commands.
* Open YouTube using voice commands.

### Entertainment Features

* Play songs directly on YouTube.
* Search and play music using voice commands.

### System Controls

* Exit the assistant using voice commands.
* Continuous listening and command execution.
